# riketpatel-site

Single-page personal site for [riketpatel.com](https://riketpatel.com).

Hosted on GitHub Pages. Plain HTML + CSS, no build step.

## Files

- `index.html` — page content
- `style.css` — styles
- `CNAME` — custom domain binding

## Deploy

Pushes to `main` deploy automatically via GitHub Pages. DNS: ALIAS / CNAME at the apex points at `omtatsat101.github.io`.
